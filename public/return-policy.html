Return & Refund Policy

Return window

Product delivery ke 3 din ke andar return request kiya ja sakta hai, agar product damaged, wrong, ya description se match nahi karta.

Non-returnable items

Perishable items, personal care products, aur custom-made items return nahi hoti — jab tak wo defective na ho.

Refund process

Return approve hone ke baad refund 5-7 working days mein original payment method (JazzCash/Easypaisa) mein process hota hai.

Return kaise request karein

Apne order history mein jaa kar seller se contact karein, ya customer support se raabta karein.
